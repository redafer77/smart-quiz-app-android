# تطبيق الاختبارات الذكي

تطبيق أندرويد عربي بالكامل لإنشاء بنك أسئلة وخوض اختبارات موقوتة، مبني بـ **Kivy** مع بناء تلقائي لملف APK عبر GitHub Actions.

<img src="assets/icon.png" width="120" align="left" hspace="16">

**المزايا**

- واجهة عربية صحيحة العرض: تشكيل اتصالي للحروف واتجاه من اليمين لليسار بدون أي مكتبة خارجية.
- **1000 سؤال جاهز** في 10 فئات (معلومات عامة، جغرافيا، تاريخ، علوم، رياضيات، إسلاميات، لغة عربية، تقنية، رياضة، أدب وفنون) و4 مستويات صعوبة، 25 سؤالاً لكل مستوى في كل فئة.
- مواضع الإجابات الصحيحة موزّعة بالتساوي على الخيارات الأربعة، فلا يمكن التخمين بلا قراءة.
- اختيار الفئة والمستوى وعدد الأسئلة قبل بدء كل اختبار.
- بنك أسئلة قابل للإضافة والتعديل والحذف مع ترشيح بالفئة وتصفّح بالصفحات، مخزَّن كـ JSON داخل مساحة التطبيق.
- اختبار موقوت مع شريط تقدّم، تنقّل بين الأسئلة، وتصحيح فوري اختياري.
- شاشة نتيجة بمراجعة كاملة لكل إجابة خاطئة مع الصواب.
- **مراجعة الأخطاء:** كل سؤال تخطئ فيه يُحفظ في قائمة مراجعة تتقلّص كلما أتقنته.
- سجل لآخر 50 محاولة، مع عرض يلخّص نسبة الإتقان في كل فئة من الأضعف إلى الأقوى.
- إعدادات: مدة الاختبار، عدد الأسئلة، خلط الأسئلة، خلط الخيارات، التصحيح الفوري.
- تصدير واستيراد بنك الأسئلة بالصيغة النصية، واستعادة الأسئلة الافتراضية بضغطة واحدة.
- التفاف صحيح للأسطر في الأسئلة الطويلة (Kivy وحده يقلب ترتيب الأسطر في النص العربي).

<br clear="left">

## التحميل

آخر APK متاح في تبويب [Actions](../../actions) داخل مخرجات آخر بناء ناجح (`smart-quiz-apk`)، أو في [الإصدارات](../../releases) عند إطلاق وسم جديد.

> البناء الحالي لمعمارية `arm64-v8a` (كل الأجهزة الحديثة تقريباً).

## بنية المشروع

| الملف | الوظيفة |
| --- | --- |
| `main.py` | الواجهة وشاشات التطبيق ومنطق الاختبار |
| `quiz_data.py` | التخزين: بنك الأسئلة، الإعدادات، سجل النتائج، قائمة المراجعة |
| `arabic_support.py` | تشكيل الحروف العربية وترتيب RTL وتسجيل الخط |
| `fonts/Amiri-Regular.ttf` | الخط العربي (رخصة OFL) |
| `data/source/*.txt` | مصدر الأسئلة، ملف نصي لكل فئة (يسهل تحريره ومراجعته) |
| `data/questions.json` | بنك الأسئلة المُولَّد والمضمَّن مع التطبيق |
| `tools/build_bank.py` | يبني `questions.json` من المصدر ويتحقق من صحّته |
| `tests/run_tests.py` | اختبارات تعمل بلا Kivy عبر بدائل خفيفة |
| `tests/font_coverage.py` | قارئ `cmap` يتحقق أن كل محرف معروض له رسم في الخط |
| `tests/bank_quality.py` | يرفض الأسئلة التي تفضح جوابها والأجوبة الحسابية الخاطئة |
| `.github/workflows/build.yml` | الاختبارات ثم بناء APK ونشر الإصدار |
| `.github/workflows/release-signed.yml` | بناء يدوي لنسخة release موقّعة للمتاجر |

## لماذا `arabic_support.py`؟

خط Kivy الافتراضي لا يحتوي حروفاً عربية، كما أن `SDL_ttf` لا ينفّذ تشكيل OpenType ولا خوارزمية BiDi.
لذلك يقوم هذا الملف بـ:

1. بناء جدول الأشكال السياقية (منفصل/أول/وسط/آخر) من `unicodedata` مباشرة، بلا جداول مكتوبة يدوياً.
2. دمج ليجاتورات لام‑ألف.
3. تطبيق نسخة مختصرة من خوارزمية BiDi (قواعد W4 و W5 و N1/N2) للحفاظ على ترتيب الأرقام والنِّسب والنص اللاتيني داخل الجمل العربية.
4. لفّ الأسطر **منطقياً قبل** التحويل البصري عبر `wrap()`؛ لو تُرك الالتفاف لـ Kivy لظهر آخر الجملة في أول سطر.

النتيجة: لا حاجة إلى `arabic-reshaper` ولا `python-bidi`، وبالتالي لا مخاطر إضافية على بناء `python-for-android`.

## إضافة أسئلة إلى البنك المضمَّن

حرّر ملف الفئة في `data/source/` بصيغة سطر واحد لكل سؤال:

</div>

```
مستوى|السؤال؟|خيار1|خيار2|خيار3|خيار4|رقم الإجابة (1-4)
```

<div dir="rtl">

ثم أعد البناء؛ يرفض السكربت الأسئلة المكرّرة أو الناقصة أو ذات الخيارات المتطابقة:

</div>

```bash
python3 tools/build_bank.py
```

<div dir="rtl">

لإضافة فئة جديدة: أنشئ `data/source/<key>.txt` وتأكد أن `<key>` موجود في `CATEGORIES`
داخل `tools/build_bank.py` و`quiz_data.py`.

### توقيع نسخة الإصدار (اختياري)

الناتج الافتراضي نسخة **debug** موقّعة بمفتاح تجريبي؛ تُثبَّت على الأجهزة عادياً
لكنها لا تصلح لرفعها على Google Play. لتوقيعها بمفتاحك، أنشئ مفتاحاً:

</div>

```bash
keytool -genkey -v -keystore release.keystore -alias smartquiz \
        -keyalg RSA -keysize 2048 -validity 10000
base64 -w0 release.keystore     # انسخ الناتج
```

<div dir="rtl">

ثم أضف في **Settings → Secrets and variables → Actions** الأسرار الأربعة:
`ANDROID_KEYSTORE_BASE64` و`ANDROID_KEYSTORE_PASSWORD` و`ANDROID_KEY_ALIAS` و`ANDROID_KEY_PASSWORD`.
عند وجودها يُنتج سير العمل نسخة `-signed.apk` إضافية ويرفعها مع الإصدار؛ وبدونها يتخطّى الخطوة بلا فشل.
هذه النسخة كافية للتوزيع الذاتي والتحديث فوق التثبيت السابق، لكنها تبقى بناء debug
يحمل `android:debuggable="true"` فيرفضه Google Play.

للحصول على نسخة صالحة للمتاجر شغّل يدوياً سير العمل **Signed Release APK** من تبويب
Actions؛ يستخدم نفس الأسرار الأربعة لكنه يبني `buildozer android release` من الأساس.
أُبقي منفصلاً ويدوياً لأنه بناء كامل إضافي (~13 دقيقة) ولئلا يؤثر على المسار المعتاد.

## صيغة ملف الأسئلة النصي

</div>

```
سؤال: ما عاصمة المغرب؟
أ) مراكش
ب) الرباط
ج) الدار البيضاء
الإجابة: ب
```

<div dir="rtl">

كل سؤال في مقطع منفصل يُفصل بسطر فارغ.

للاستيراد على الجهاز: ضع الملف باسم `questions_import.txt` داخل
`/sdcard/Android/data/org.quizapp.smartquizapp/files/` ثم اضغط **استيراد** في شاشة إدارة الأسئلة.
زر **تصدير نصي** يكتب في المجلد نفسه.
